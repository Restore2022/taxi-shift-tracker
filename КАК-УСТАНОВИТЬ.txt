  TAXI СМЕНА — КАК УСТАНОВИТЬ НА ТЕЛЕФОН
═══════════════════════════════════════

1. Получите файл TaxiSmena.apk
   (Telegram, WhatsApp, USB — как удобно)

2. Нажмите на файл → «Установить»

3. Если спросит «Разрешить установку?» — нажмите ДА
   (это нужно один раз)

4. Откройте приложение «Taxi Смена»

5. При первой смене нажмите «Разрешить» для GPS

═══════════════════════════════════════

Всё работает БЕЗ интернета.
Данные хранятся только на вашем телефоне.

Приложение не удаляйте — там вся история!
