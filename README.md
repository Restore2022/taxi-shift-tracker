# Taxi Смена — учёт смены таксиста

Приложение для Android. **Работает полностью автономно** — без сервера, без интернета, все данные на телефоне.

---

## Для водителя (установка за 1 минуту)

1. Получите файл **`TaxiSmena.apk`** (через Telegram, WhatsApp, USB или Bluetooth).
2. Нажмите на файл → **«Установить»**.
3. Если телефон спросит — разрешите установку из этого источника (один раз).
4. Откройте приложение **«Taxi Смена»**.
5. При первой смене нажмите **«Разрешить»** для GPS.

**Всё.** Больше ничего настраивать не нужно.

---

## Для вас (собрать APK один раз)

APK нужно собрать **один раз** на компьютере, потом просто раздавать файл водителям.

### Способ 1 — Android Studio (проще всего)

1. Скачайте [Android Studio](https://developer.android.com/studio) (бесплатно).
2. Откройте папку `android` из этого проекта.
3. Меню **Build → Build APK(s)**.
4. Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`
5. Переименуйте в **`TaxiSmena.apk`** и отправьте на телефон.

### Способ 2 — GitHub (без Android Studio)

1. Загрузите проект на GitHub.
2. Вкладка **Actions** → workflow **Build APK** → **Run workflow**.
3. Скачайте готовый APK из артефактов.
4. Переименуйте в **`TaxiSmena.apk`**.

### Способ 3 — Скрипт (если Android Studio уже установлена)

Дважды нажмите **`android/СОБРАТЬ-APK.bat`**.

## Возможности

| Функция | Описание |
|---------|----------|
| **Смены** | Открыть/закрыть, несколько раз в день |
| **GPS-пробег** | Считается автоматически во время смены |
| **Поездки** | Сумма + способ оплаты (нал / карта / приложение) |
| **Комиссия** | −30 ₽ с каждого заказа автоматически |
| **Расходы** | Бензин, мойка, аренда, прочее |
| **Отчёты** | День, вчера, неделя, месяц, свой период |

**Чистый доход** = поездки − комиссия − расходы

## Структура проекта

```
taxi-shift-tracker/
├── android/          ← Android-приложение (APK)
│   └── app/src/main/assets/  ← веб-часть внутри APK
├── css/
├── js/
├── index.html
└── README.md
```

Папки `css/`, `js/`, `index.html` — исходники интерфейса. При сборке APK они копируются внутрь приложения.

---

## Обновление приложения

1. Измените файлы в `css/`, `js/` или `index.html`.
2. Пересоберите APK (Android Studio или GitHub Actions).
3. Отправьте новый `TaxiSmena.apk` на телефон.
4. Установите поверх старой версии — **данные сохранятся**.
